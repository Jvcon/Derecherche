Palette workbench

Open the Palette directly with a chosen query and starting category. This page is for iterating on layout, density, keyboard flow, and the recommendation strip.

Try: the input starts on common engines; press TAB to enter category mode, TAB again to drill into a category. Enter opens the highlighted engine, and ⌘K/Ctrl+K opens the action menu. The Palette is rendered in a Shadow DOM host so host-page CSS cannot leak in.
